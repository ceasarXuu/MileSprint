# MileSprint 设备管理对抗性审查

基线与回退检查点：`411f34a`。目标是单进程 SQLite 服务经 MCP/CLI 对现有设备完成发现、登记、查询、租约、轮询和声明式策略检查。范围为 `milesprint/`、构建配置及使用说明。保持 PRD PD1–PD9 和用户批准的模块化架构。真实设备只读探测，租约仅更改本地台账。禁止设备执行、镜像、新建模拟器和未授权单元/集成测试。自动轮次上限两轮。

## 第一轮

新建内部审查会话 `/root/device_review`，fork_turns=none，15 分钟预算，正常完成。输入仅包括仓库绝对路径、基线、目标文件、PRD/契约、上述目标和约束，以及并发、身份、TTL、策略绕过、故障状态、易用性和完整性检查。审查者只读，没有继承会话或执行测试。启动及输出可追溯至对话工具记录。

| 发现 | 处理与证据 |
| --- | --- |
| R1 身份冲突仍可能通过 UDID 匹配，USB 单源及拔出状态缺失 | accept。契约 E1 与原采集条件 E2。ECID 冲突置为不可登记，验证缺字段设备与 USB 信息，单独返回 USB 在位。保留 USB 单源候选。 |
| R2 无线及陈旧观察可取得用途租约 | accept。计划有线约束 E1。授租前刷新，事务中检查 15 秒新鲜度，对真机执行用途要求已核验有线。 |
| R3 Bundle ID 尾空格绕过保护，整机 reset 忽略 App override | accept。原字符串查找路径 E2 与保护范围 E1。统一 Bundle ID 校验，存在受保护 App 时拒绝整机重置。 |
| R4 慢资源探针阻塞目录，轮询异常退出 | accept。共享锁路径 E2。分开采集、合并刷新请求、限制资源并发，捕获轮询异常并记录。 |
| R5 缺少停用、审计、只读详情和容量门槛 | accept。PRD/契约 E1。增加停用和审计记录，接入按需只读详情及最小可用容量条件。 |
| R6 TTL 宽松转换 | accept。SDK 参数校验路径 E2。MCP 参数使用严格正整数。 |
| R7 成功输出为通用 envelope | defer。实际字段稳定，细化逐工具 schema 由后续接口硬化跟踪，当前通过 CLI 文档提供使用方式。 |
| R8 启动和调用示例缺失 | accept。独立运行说明补齐配置、发现和租约操作。现有 README 含其他工作树编辑，保留原内容。 |

治理决策 `continue-current-round`。修复保持在既有目标，停用入口、审计和容量约束依据既有 PRD。第一轮未证明性能收益，不声明吞吐或采集时延指标。已经由 MCP 和 CLI 在隔离台账上对本机现有真机与模拟器完成发现、登记、查询、持有、释放和策略查询。

治理决策 `start-closure-round`。第二轮仅复核 R1–R6、R8 及直接回归。审查和验证不写入设备。

## 第二轮

新建内部审查会话 `/root/device_closure`，fork_turns=none，15 分钟预算。启动记录见对话工具。只读复核 R1–R6、R8 与直接回归，未继承主会话。输入指向本报告、当前 `milesprint/` 和 `usage.md`，要求记录反例、路径、证据等级与所需验证。

定向实机验证在临时 SQLite 上经正常 CLI/MCP 入口完成。目录发现 9 个模拟器、4 条真机记录，1 台 USB 在位真机。以现有模拟器和 USB iPad mini 分别完成登记、查询、持有、释放。另验证 preserve 拒绝卸载、带尾空格的 App ID 拒绝重置、云数据范围拒绝，iPad mini 的详情、锁状态及 DDI 查询均返回成功。源码分发包和 wheel 均构建成功。

第二轮已完成。R4、R5、R6 的原缺口有静态修复证据。以下项目尚未关闭：

- R1/R2：accept。契约 E1 要求跨源 ECID 核验。采集和授租路径 E2 仍可在 USB 缺 ECID 时凭相同 UDID 判定已核验有线。另有冲突 USB 行被后续 CoreDevice 行再次认领的反例。需将 USB 在位与身份核验拆开，先排除全局冲突，再允许真机用途租约。
- R3：accept。当前覆盖按原大小写查找。Apple 明确 Bundle ID 大小写不敏感（E3）。混合大小写输入仍可能退回默认 resettable。需统一写入和查询键，并对历史键保守归并。 [Apple Bundle ID](https://developer.apple.com/help/glossary/bundle-id/)
- R8：accept。使用说明应明确把响应 `id` 映射为请求字段 `lease_id`。接口签名是 E2 证据。

Status: blocked
治理决策 `stop-non-convergent`，控制结果 `user-decision-required`。两轮已用完，身份和策略两类原始问题仍有反例。当前实现增加本机 SQLite 台账和 MCP 入口，实测仅在临时目录产生台账。保留已跑通的主流程与基线 `411f34a`，issue 保持 open。可选方案是批准一次仅复核上述问题的额外轮次，或以当前提交保留开发成果、暂停发布验收。没有新增设备操作范围。
